# Data Structures Practice

This repository contains implementations of fundamental data structures for learning and practice.

## Purpose
The goal is to build a strong understanding of core data structures by implementing them from scratch and applying them in simple scenarios.

## Topics
- Arrays
- Linked Lists
- Stacks
- Queues
- Trees
- Graphs

## Approach
Each topic includes:
- Basic implementation
- Core operations
- Simple usage examples

## Notes
This is an ongoing learning repository and will be updated regularly.
